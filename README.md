# backend 

Backend de Gesnotes, plateforme numérique de suivi des notes scolaires 
connectant enseignants, parents et administration.

Gère la saisie des notes par les enseignants, le calcul automatique des 
moyennes (élève, matière, classe) et l'envoi de notifications temps réel 
aux parents via Firebase Cloud Messaging.

**Stack :** Express.js, TypeScript, PostgreSQL, JWT (auth par rôle), FCM
**Rôles gérés :** Admin école, Enseignant, Parent
